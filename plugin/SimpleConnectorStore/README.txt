Simple Connector Store v1.0.0
=============================

1. Download SimpleConnectorStore.jar from Admin Panel → Connect Server → Download Plugin
   (URL is filled automatically — you do NOT need to type website URL)

2. Put the JAR in your Paper/Spigot plugins folder and start once.

3. Edit plugins/SimpleConnectorStore/config.yml — only set:
   connect-code: paste code from Admin Panel

4. Restart server.

5. From website Admin → Connect Server you can:
   - See online status
   - Send ANY console command (runs as console on the MC server)

Command notes:
- Do not use leading / in commands. Console runs without slash.
- Website strips / automatically if you still type /give ...
